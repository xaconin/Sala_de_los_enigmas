Acerca del proyecto

¿Qué es La Sala de los Enigmas?

La Sala de los Enigmas es un blog que ha sido pensado para entrener, ademas de entrenar la mente de paso.

Objetivos

El proyecto pretende combinar entretenimiento y aprendizaje mediante actividades sencillas. Se busca que el usuario pueda participar, comprobar sus respuestas y conocer su puntuación.

Tecnologías utilizadas

  • HTML5: para estructurar el contenido de las páginas.
  • CSS3: para definir los colores, estilos y presentación visual.
  • Bootstrap 5: para organizar los elementos y facilitar el diseño adaptable.
  • JavaScript: para añadir interactividad a los juegos y comprobar las respuestas.

Desarrollo del proyecto

La web se ha construido mediante diferentes páginas HTML conectadas entre sí a través de un menú de navegación. Se ha utilizado una hoja de estilos CSS común y diferencia por secciones para mantener una apariencia uniforme en todo el sitio.

Las comprobaciones de resultados, marcadores y funcionalidades se han desarrollado con JavaScript, mediante pequeños programas que permiten generar operaciones matemáticas, comprobar adivinanzas y resolver retos numéricos.

Para facilitar la organización del proyecto, los archivos JavaScript se encuentran en una carpeta independiente, mientras que las imágenes están agrupadas en otra carpeta. Quedando las diferentes paginas en la carpeta raiz del proyecto.
